📌 User Module Overview

The User module provides an interface for end users to interact with the trained sentiment analysis model. Users can submit textual data for sentiment classification and provide feedback on the system’s predictions.

🧠 Sentiment Prediction Process

User-provided text is processed using a transformer-based deep learning model trained through transfer learning. The model classifies the input text into sentiment categories.

  • Input text acquisition
  • Tokenization using DistilBERT tokenizer
  • Deep neural inference
  • Sentiment classification (Positive / Negative)

📜 Prediction History Management

Each sentiment prediction made by the user is securely stored in the database. Users can view and manage their prediction history for transparency and analysis.

🗣️ Feedback Submission & Tracking

Users can submit feedback regarding model predictions. Feedback includes quantitative ratings and qualitative remarks, which are reviewed by the Controller module.

  • Rating-based evaluation
  • Short textual feedback
  • Status tracking (Pending / Reviewed)
  • Controller remarks visibility

🔐 Security & Access Control

User actions are protected using role-based authentication, ensuring that only authorized users can access prediction and feedback features.

🎯 User Responsibilities

  • Provide meaningful input text for prediction
  • Review prediction results responsibly
  • Submit constructive feedback
  • Maintain account confidentiality

📌 Project Overview

This project implements a deep learning-based sentiment analysis system using transfer learning to analyze textual data collected from multiple sources. The system classifies user-provided text into Positive or Negative sentiments with high accuracy.

🧠 Algorithm & Technology

  • Algorithm: DistilBERT
  • Full Form: Distilled Bidirectional Encoder Representations from Transformers
  • Model Type: Transformer-based Deep Neural Network
  • Learning Method: Deep Transfer Learning
  • Frameworks: PyTorch, Hugging Face Transformers
  • Backend: Flask
  • Database: MySQL

📂 Multi-Source Data Fusion

Multiple datasets from different sources are preprocessed and combined to form a unified training dataset. This improves model generalization and robustness across diverse sentiment expressions.
